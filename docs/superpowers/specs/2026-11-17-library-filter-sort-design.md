# 阅读中心筛选与排序

用户已确认并授权实现以下方案。

## 规则

- 筛选：全部、在读、未读。是否存在 progress 记录决定分类；0% 和 100% 只要有记录都属于在读。
- 默认全部、按最近阅读时间降序。提供进度与最近阅读时间两种排序及升序/降序。
- 最近阅读时间沿用 progress.at（最后保存进度时间），手动设置进度也会更新，不新增计时记录。
- 时间排序中未读及缺失/无效时间记录始终排末尾；进度排序中未读为 0%。相同排序值按中文书名升序，再按路径确定顺序。
- 子目录保留在书籍前，不参与筛选排序。空结果在子目录之后提示，并可切回全部。
- 本次选择保留至页面卸载，不增加持久化偏好；刷新数据、切换目录、重置和保存进度后继续按当前条件派生列表。

## 实现计划

1. 在客户端添加纯列表派生函数，filter 产生新数组后排序，不改变接口返回的数据。
2. 目录栏下添加筛选按钮组、排序字段和方向下拉框及可见/总数提示；沿用现有主题样式，窄面板允许换行，添加可访问标签。
3. 无结果提示与目录导航共存。筛选改变时收起进度编辑器，避免隐藏后留下编辑状态。
4. 添加组件测试覆盖两个方向、筛选组合、0%/100%、时间缺失、同值排序、列表不可变、目录保留和重置后重新筛选。
5. 更新中英文说明，运行语法检查和完整测试，并尽可能验证现有 GUI。无浏览器连接时明确说明未完成视觉验收。

## 自查

无需修改后端、数据格式、已有笔记归档功能或读取正文行为。时间不是累计时长；时间缺失不伪造为某个日期。默认和边界条件已明确。
