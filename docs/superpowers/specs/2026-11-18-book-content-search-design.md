# 书内正文检索

2026-11-18：用户已确认匹配、分页、性能和进度规则，授权按本设计实施。

## 行为契约

- 当前书籍中按字面子串检索，忽略英文大小写；去除查询首尾空白，内部空白保留。查询最多 100 个 Unicode 字符，不跨段、不支持正则。每处不重叠命中分别展示。
- 每页默认 20 条、最多 50 条，用游标续页；卡片只渲染当前页，支持返回上一页。结果含段落号、可用章节和有界上下文，原文通过已有段落接口按需加载。
- 打开搜索时暂停，保留段落、已显示字符、原段落窗口和阅读区滚动位置。输入、翻页和命中预览都不写进度；关闭搜索与「返回原位置」恢复该位置并保持暂停。
- 预览中选择「从此处继续阅读」才退出搜索并恢复正常阅读，后续按原有 1.2 秒防抖规则写进度。搜索期间如阅读中心明确设置或重置进度，以该操作为准，旧快照失效。
- 搜索请求使用 250 ms 防抖、取消及请求版本校验；预览加载也验证版本。关闭、切书、切会话或卸载后，旧响应不能更改当前位置。
- 空查询、无结果、无效查询/游标、解析错误和预览加载失败均有反馈，可重试。查询与结果作为 React 文本节点渲染，命中以 mark 包裹，无 HTML 注入、不调用模型、不写正文到会话事件。

## 实现边界

Host 的独立搜索模块扫描 loadBook 已解析的所有段落，跳过图片；分块扫描并定期让出事件循环，支持取消。GET /dsh-read/api/search 复用既有路径白名单与错误封装，不注册模型工具、不写阅读进度。游标绑定书籍和查询，结果片段有界；不建立跨书索引。

Browser 在当前卡片内按需展开搜索区。检索结果与预览状态同阅读引擎隔离；进入搜索同步屏蔽播放及进度防抖，冻结已有窗口加载。预览重新取目标段落窗口、完整显示目标段落并滚动到命中标记。返回时恢复原窗口和字符位置，避免再次加载失败阻碍返回。临时搜索不会成为跨会话恢复的阅读进度。

## 验证与性能

- 纯搜索测试：中文/英文/特殊字符、多个命中、分页边界、长段落、空查询、游标校验、取消、章节与偏移、所有现有解析格式。
- Host 测试：HTTP 校验、错误、格式支持、只返回有界片段、搜索及翻页不改进度、不增加模型工具。
- Client 测试：防抖及乱序响应、页切换、跨窗口跳转、高亮、原位置精确恢复、进度保存边界、明确进度更改、失败重试、卸载/切书/切会话失效。
- 约 10 MiB、5 万段的可复现合成长书，缓存下首屏/续页 P95 ≤ 500 ms（各 20 次），首次解析另记。真实浏览器输入处理和当前页渲染各 ≤ 100 ms，250 ms 防抖另记。
- 完整 npm test、变更文件 node --check、git diff --check；无新增运行时依赖、无构建步骤。

实施顺序：搜索模块与测试 → Host 接口与测试 → 卡片交互与回归 → 浏览器及长书性能 → 使用文档和交付。
