# DSH-3 实施计划

设计已经用户确认。沿用现有 Node / React bundle，不增加存储字段或运行时依赖。

1. Host：增加纯定位校验函数；按书路径与批注 ID 读取记录，重新解析原书，返回已校验正文窗口。
   文件缓存验证源文件状态；解包 EPUB 每次重新解析以识别子文件变化。为分页增加可选正文版本校验。
2. 客户端：保留完整按书批注列表，增加纯展示面板、展开控制、回答状态、加载／空态／重试；
   正文标记筛选并展开同段批注，打开面板暂停且保留光标。
3. 定位：一次性应用 Host 返回的正文与书籍元数据，完整显示并高亮／滚动到目标，保持暂停；
   使用上下文和导航请求序号隔离过期响应，失败保留位置。
4. 测试：验证列表与问答状态、同段多条、定位窗口外目标、缺失／变化／歧义、加载失败重试、
   切书／会话和导航竞态；保留归档与续读回归。
5. 文档与交付：更新两种语言 README；执行 `npm test`、JavaScript 语法检查及 `git diff --check`；
   提交并通过 `hifox repo push` 发布任务分支，给出改动和验证结果供验收。
