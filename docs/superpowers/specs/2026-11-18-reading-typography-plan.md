# 阅读排版实施计划

依据：[已确认设计](2026-11-18-reading-typography-design.md)。

1. 在客户端增加独立的偏好校验、加载、保存及同页订阅；保留既有播放和段落状态。
2. 给阅读正文添加作用域内的 CSS 变量和宽度容器，底部增加可折叠的排版控件与恢复默认。
3. 复用客户端测试工具验证持久化、独立调整、容错、同步，以及不同播放状态下的正文与进度不变。
4. 用浏览器验证原生控件键盘行为、窄窗口换行和图片比例；修复实际发现的布局问题。
5. 更新中英文使用说明，运行完整 Node 测试及改动文件的语法检查，检查最终 diff，提交并推送任务分支供人工审阅。
