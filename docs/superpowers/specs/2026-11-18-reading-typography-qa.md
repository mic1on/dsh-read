## 在 DSH 中复测

1. 将当前工作目录软链为 web profile 插件（`dsh plugin --profile web add -w link:/absolute/path/to/dsh-read`），重启 DSH，打开一本包含插图的书。
2. 读到段落中间暂停，记下已显示文字和进度；打开「排版」，独立修改三项，恢复默认，确认上述状态及输入框样式不变。
3. 保持播放时调整，确认继续原来的字符和段落；同一页面另一张卡片应同步排版。
4. 调整后重开阅读器与刷新页面，确认偏好保留；按 Tab、方向键和空格测试控件，空格不触发卡片播放。
5. 缩至约 320px 宽，设置最大字号/行距与 900px 宽度，检查无横向溢出、长文本换行和图片比例；短窗口内滚动设置区可操作全部控件。
