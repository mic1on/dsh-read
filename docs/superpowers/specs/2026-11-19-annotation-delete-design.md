# 本书批注删除

日期：2026-11-19
任务：DSH-7

## 范围与交互

复用 `POST /dsh-read/api/notes` 的 `{ path, remove: id }`，不改变接口、存储格式或归档身份校验。
每条批注的摘要旁始终显示“删除”，无需展开长回答即可发现入口。点击后在条目内确认，
说明将删除批注、已保存问答以及当前归档目录中对应的 Markdown 文件（包括其中手写内容）；
提供“确认删除”和“取消”。删除不会移除原会话消息。

备选是仅在展开后显示删除，或放入更多菜单；前者在长回答中难发现，后者增加寻找步骤。
采用直接显示按钮与条目内确认，沿用现有组件和主题。

## 数据与异常

- 成功后使用服务端返回的剩余记录更新列表、标题数量和正文标记，保留阅读位置与暂停状态。
- 请求进行中防止重复提交，暂禁刷新、定位和其他删除；返回阅读、切书或切会话仍可用。
- 网络或服务端失败保留记录、显示错误并允许重试；不提前隐藏记录。
- JSON 已删除而 Markdown 删除失败时，记录仍从列表移除，另显示可重试的 Markdown 删除提示。
  重试提示保留在当前卡片内，不改变存储格式；页面重载或切书后不保留。
- 作废删除前及删除期间的列表请求，防止迟到的读取恢复旧记录；同书其他已挂载卡片刷新。
- 请求绑定书籍、会话、正文版本及挂载状态，旧响应不能修改新上下文。

## 实施与验证

1. 为纯展示面板加入摘要操作区、确认区和 Markdown 错误重试提示。

4. 验证真实 Host 删除与归档隔离，更新中英文使用说明；运行全量测试、语法及空白检查。

不新增运行时依赖、构建步骤、批量删除或编辑功能。
