# 阅读排版偏好

DSH-4 的交互与范围已在任务对话中确认（2026-11-18）。沿用手写客户端 bundle、React 和浏览器本地偏好，不新增宿主接口或主题系统。

## 交互与默认值

阅读卡片底部控制栏增加「排版」按钮，展开紧凑面板。使用原生滑杆调整字号（12–28px，步长 0.5px）与行距（1.4–2.4 倍，步长 0.05），原生下拉框选择正文宽度（全宽、560、720、900px）。默认值为 14.5px、1.95 倍、全宽，与原始排版一致。

每次调整即时作用于阅读正文并保存；「恢复默认」只恢复这三项。控件保留原生键盘行为、可访问名称和可见焦点；卡片的空格播放快捷键忽略这些控件。按钮用 `aria-expanded` 表达面板状态。

## 偏好与状态隔离

以 `dsh-read:typography` 存储带 `version: 1` 的 JSON，作用域为当前浏览器、当前站点，跨书籍和会话。模块保存当前值并通知同一页面已挂载的阅读器，新卡片和重新加载恢复保存值。与播放速度、自动暂停、阅读进度分别存储。

偏好只向正文容器提供 CSS 变量。正文宽度按卡片可用空间收缩并居中，插图跟随同一宽度且保持比例。排版控件不会重新挂载阅读器、重新加载段落、改变已显示字数、保存阅读进度或改变播放意图。

非法 JSON、非对象、未知版本回退默认；无版本旧对象允许恢复合法字段。字段分别校验，有限数字按范围和步长归一化，其他类型回退该字段默认值，宽度只接受明确选项。存储读取或写入失败不阻止阅读，当前页面继续保留内存设置。

## 布局与验证

正文用独立容器约束最大宽度；长单词可以换行，图片最大宽度包含边框。控制栏和设置面板允许换行，短窗口下设置区域可以滚动，正文保有可滚动空间。

沿用现有 Node 客户端测试，补充独立设置、同页同步、重开恢复、默认恢复、异常/旧版本、存储失败，以及暂停/播放/读完状态下不丢正文、不跳段、不写进度的回归。浏览器检查 320px 等窄窗口、字号/行距上限、宽度收缩、长文本、插图比例和键盘操作。运行完整测试与语法检查，更新中英文 README。
